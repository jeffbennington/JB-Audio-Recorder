# JB Audio Recorder

<img width="1098" height="529" alt="Screenshot" src="https://github.com/user-attachments/assets/2c1b1078-ca96-49c1-856e-38b3b79cd5fc" />

Ihr Sound unter voller Kontrolle! JB Audio Recorder ist ein leichtes und leistungsstarkes Audioaufnahme-Tool für alle, die Wert auf Qualität legen. Vergessen Sie komplizierte Einstellungen: Nehmen Sie Audio in gängigen Formaten mit wählbarer Bitrate und Frequenz auf. Der integrierte intelligente Rauschunterdrückungsalgorithmus befreit Ihre Stimme von Hintergrundgeräuschen.

Komfortabler Player und Bibliothek. Kein lästiges Suchen nach Dateien im gesamten System mehr. Hören Sie Ihre Aufnahme direkt in der App an und entscheiden Sie — speichern oder erneut aufnehmen. Alle gelungenen Aufnahmen landen in einer übersichtlichen Bibliothek, wo sie leicht gefunden und mit einem Klick geöffnet werden können.

Arbeiten Sie so, wie es Ihnen passt. Der Recorder kann im Hintergrund arbeiten oder mit dem «Immer im Vordergrund»-Modus stets griffbereit sein. Steuern Sie die Aufnahme mit Tastenkombinationen und machen Sie sich keine Sorgen um das Ergebnis — das System warnt Sie beim Beenden, wenn eine Datei nicht gespeichert wurde.
